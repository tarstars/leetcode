Given `n` non-negative integers representing an elevation map where each bar has width `1`, compute how much rain water can be trapped after raining.

Example 1:

```text
Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
```

Example 2:

```text
Input: height = [4,2,0,3,2,5]
Output: 9
```

Constraints:

- `1 <= n <= 20000`
- `n == height.length`
- `0 <= height[i] <= 100000`
