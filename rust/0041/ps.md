Given an unsorted integer array `nums`, return the smallest positive integer that does not appear in the array.

Your algorithm must run in `O(n)` time and use `O(1)` additional space.

Example 1:

```text
Input: nums = [1,2,0]
Output: 3
```

Example 2:

```text
Input: nums = [3,4,-1,1]
Output: 2
```

Example 3:

```text
Input: nums = [7,8,9,11,12]
Output: 1
```

Constraints:

- `1 <= nums.length <= 100000`
- `-2^31 <= nums[i] <= 2^31 - 1`
